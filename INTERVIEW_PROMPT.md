# Interview Prompt

I want to build a persistent context system for AI agents.

Use this model:

`Root → Domain → Project → supporting docs`

Interview me in small steps to define the structure, rules, and initial content.

Key goals:
- progressive discovery, not loading everything
- current truth separate from semantic history
- one canonical home for each fact
- material high-confidence changes update context automatically
- simple structure; avoid unnecessary metadata or duplication

Derive the Domains and Projects from my actual work rather than forcing a predefined taxonomy.

As we go, keep track of agreed decisions and unresolved choices. Challenge duplication, unclear ownership, and unnecessary complexity.

At the end, produce the concise canonical rules, schemas, and initial structure another agent can follow.
